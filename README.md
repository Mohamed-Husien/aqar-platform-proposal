# وثيقة العرض الفني والمالي الرسمي | منصة إيجار العقارات وإدارة الوسطاء (Real Estate Rental Marketplace)

عرض فني وهندسي معتمد لتنفيذ منصة ومنظومة إيجار العقارات والوحدات السكنية والتجارية والفندقية وإدارة الوسطاء (Brokers) والشركات والملاك عبر تقنية **Flutter** لتطبيقات الموبايل (iOS & Android) و **Laravel 11 REST API** للباك إند وقاعدة البيانات المركزية ولوحة التحكم السحابية Web.
